# AW-Rocov

Чистая, оригинальная реализация recovery-EA для **MetaTrader 5 (MQL5)**.
Советник не генерирует входные сигналы — он управляет уже существующей
корзиной позиций и пытается вернуть её к небольшой плановой прибыли,
используя четыре кирпичика:

1. **Замок** — встречная позиция, замораживающая плавающий убыток
   (требуется hedging-счёт).
2. **Сетка усреднения** — последовательные ордера в сторону восстановления
   с заданным шагом в пунктах. Объём считается по выбранной схеме:
   - `GEOMETRIC` — классический мартингейл `L_n = L_{n-1} × множитель`
     (сумма растёт как `mult^N`).
   - `HARMONIC` — гармоническая последовательность `L_n = L_base / (n+1)`
     (сумма растёт как `L_base × ln N`, экспозиция конечна).
   - `LINEAR` — `L_n = L_base × (1 + n × k)` (под-квадратичная сумма).
3. **Частичный Take Profit** — закрытие частей прибыльных позиций по пути
   к безубытку, что снижает экспозицию и приближает среднюю цену корзины
   к рынку.
4. **BE-охота** — режим «recovery via redistribution»: по достижении
   потолка усреднений новые рыночные ордера не открываются. Движок
   считает точку безубытка корзины `P_BE` и ждёт, пока цена сама её
   достигнет. При застое (нет прогресса в течение N секунд) принудительно
   закрывается часть позиции с худшим PnL — `P_BE` сдвигается к рынку.

> Это самостоятельная реализация публично описанной идеи.
> **Это не клон, не декомпиляция и не производное** какого-либо коммерческого
> продукта.

## Структура репозитория

```
AW-Rocov/
├── README.md
├── docs/
│   └── strategy.md                — алгоритм и описание состояний (AWRocov)
└── MQL5/
    ├── Experts/
    │   ├── AWRocov.mq5            — recovery-EA (управляет корзиной, без входов)
    │   └── AWScalper.mq5         — скальпер с мартингейлом (генерирует входы)
    └── Include/AWRocov/
        ├── Logger.mqh             — логгер с уровнями
        ├── TradeOps.mqh           — обёртка CTrade + нормализация (+ SL/TP)
        ├── BasketManager.mqh      — снапшот корзины
        ├── Panel.mqh              — кнопки BUY / SELL / CLOSE ALL
        ├── RecoveryEngine.mqh     — конечный автомат (AWRocov)
        ├── SignalEngine.mqh       — сигналы EMA-тренд + RSI-откат + ATR (AWScalper)
        └── ScalperEngine.mqh      — торговый цикл + мартингейл (AWScalper)
```

Папка `MQL5/` повторяет структуру терминала MetaTrader 5, поэтому её содержимое
можно поместить напрямую в `MQL5/` каталога данных терминала.

## Установка

1. В MT5: `Файл` → `Открыть каталог данных`.
2. Скопируйте `MQL5/Experts/AWRocov.mq5` в `MQL5/Experts/`.
3. Скопируйте папку `MQL5/Include/AWRocov/` в `MQL5/Include/AWRocov/`.
4. Откройте `AWRocov.mq5` в MetaEditor и нажмите `F7` (Компиляция).
5. Перетащите `AWRocov` на график.

> **Кодировка.** Файлы сохранены в UTF-8 без BOM. Современные сборки
> MetaEditor (build 4000+) корректно их распознают. Если кириллица
> отображается некорректно, в MetaEditor выберите `Файл` → `Сохранить как…`
> → кодировка **UTF-8**, либо переключите кодировку файла через пункт
> меню «Кодировка».

## AWScalper — скальпер с мартингейлом (XAUUSD M1/M5)

Отдельный советник `MQL5/Experts/AWScalper.mq5`. В отличие от AWRocov, он
**сам генерирует входы** и торгует по **одной позиции за раз**.

**Логика входа (тренд + откат):**

1. Тренд-фильтр: `EMA(fast)` против `EMA(slow)` — направление контекста.
2. Вход по откату RSI внутрь тренда (контр-импульсный — даёт высокий
   винрейт на мелком TP, что и нужно мартингейл-циклу):
   - тренд вверх + `RSI <= InpRsiBuyLevel` → **BUY**;
   - тренд вниз + `RSI >= InpRsiSellLevel` → **SELL**.
3. TP/SL — адаптивные по ATR (`InpUseATRTargets=true`) или фиксированные
   в пунктах. Сигнал читается с последнего **закрытого** бара (без репэйнта).

**Мартингейл по числу подряд убыточных сделок** (`step`):

| Схема       | Формула                  | Поведение                       |
| ----------- | ------------------------ | ------------------------------- |
| `GEOMETRIC` | `L = base × mult^step`   | классический мартингейл         |
| `LINEAR`    | `L = base × (1 + step×k)`| мягкий линейный рост            |
| `HARMONIC`  | `L = base / (step + 1)`  | убывающий («регрессия» лота)    |

Прибыльная сделка сбрасывает `step` в 0; убыточная — увеличивает (до
потолка `InpMaxMartSteps`).

### Режим усреднения (мартингейл-сетка)

Включается `InpUseAveraging = true`. Тогда вместо «одна позиция со SL/TP»
EA работает **корзиной**: первый ордер открывается по сигналу, а если цена
идёт против — **доливает** ордера той же стороны через шаг сетки
(`InpGridStepPoints` или `ATR×InpGridStepAtrMult` при `InpGridStepUseATR`).
Лот долива растёт по **числу уже открытых ордеров** — `LotForStep(кол-во)`,
то есть та самая «регрессия по количеству ордеров». Вся корзина закрывается
разом по профит-таргету: `InpBasketTpMoney` (в валюте счёта, приоритет)
либо `InpBasketTpPoints` (пункты от средневзвешенной цены).

Ограничители корзины: `InpMaxAveragingOrders` (потолок числа ордеров) и
тот же аварийный DD-стоп. Индивидуальные SL/TP и трейлинг в этом режиме
не применяются — выход только всей корзиной.

> ⚠️ **Усреднение усиливает «хвостовой» риск.** При затяжном тренде против
> корзины ордера копятся, средний лот и плавающий убыток растут.
> `InpMaxAveragingOrders` и `InpMaxDrawdownStopPct` — обязательные
> ограничители. Тестировать **только на демо**.

**Предохранители:** потолок шагов + опц. сброс после потолка
(`InpResetAfterMax`), абсолютный кэп лота (`InpMaxLot`), фильтр спреда
(`InpMaxSpreadPoints` — критично для золота), торговое окно по часам и
**аварийный стоп по просадке эквити** (`InpMaxDrawdownStopPct`): при
превышении порога все позиции закрываются и торговля останавливается.

> ⚠️ **Мартингейл несёт «хвостовой» риск обнуления депозита.** Серия из 10
> убытков при множителе 1.5 раздувает лот в ~57 раз, при 2.0 — в 512 раз.
> Аварийный стоп — обязательный спасатель, а не «страховка от слива».
> Тестируйте **только на демо** и на длинной истории, включающей затяжные
> тренды против позиции.

## Дисклеймер

Recovery / averaging-стратегии несут значительный «хвостовой» риск.
Используйте советник **только на демо-счёте**, пока вы полностью не
поймёте взаимодействие параметров.
Программное обеспечение поставляется «как есть», без каких-либо гарантий.
